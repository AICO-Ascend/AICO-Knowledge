# MEDUSA: Simple LLM Inference Acceleration Framework with Multiple Decoding Heads

> [!abstract] 摘要（原文）
> 1\. 🚀 MEDUSA 框架通过在大型语言模型上添加多个解码头，实现了多个后续 Token 的并行预测，从而显著降低了自回归推理的延迟。 2. 🛠️ 该方法提出了 MEDUSA-1 和 MEDUSA-2 两种微调策略，并结合树状注意力机制（Tree-based Attention）和典型的接受方案，在不牺牲生成质量的前提下实现了 2.3 至 2.8 倍的推理加速。 3. 💡 此外，MEDUSA 还引入了自蒸馏（Self-distillation）流程，使其无需原始训练数据即可适配多种模型，为提升 LLM 推理效率提供了一种简单且易于集成的通用解决方案。

在论文实验链路中，它分解各模块边际贡献，与 Figure 3（baseline / Medusa-1 / Medusa-2 端到端 wall-time 对比）形成"组件级→系统级"的双层证据链，支撑 Medusa-2 显著超越 baseline 的核心结论。
