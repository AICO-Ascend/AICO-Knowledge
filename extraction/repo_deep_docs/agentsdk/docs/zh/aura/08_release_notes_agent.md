# Agent SDK 26.1.0 版本说明 — 一体化解读

## 【定位】

这篇文档是 Agent SDK 26.1.0 Release 版本的版本说明（Release Notes），主要描述该版本 Aura 组件的版本配套关系（与 CANN、Ascend HDK 的兼容性）、新增特性（共卡模式训练、分离模式训练、qwen3 系列模型支持）、升级影响及配套文档清单，供运维和开发人员确认升级可行性与新能力范围。

## 【技术要点】

1. **版本形态**：Agent SDK 26.1.0 为 Release 版本（原文："版本类型 — Release版本"），无历史兼容性包袱（原文："本版本无兼容性问题"）。
2. **配套 CANN**：CANN 9.1.0；同时兼容 CANN 9.0.0（CANN 兼容矩阵中 9.0.0 与 9.1.0 两列均为 Y）。
3. **配套 Ascend HDK**：Ascend HDK 26.1.0；同时兼容 Ascend HDK 26.0.RC1（HDK 兼容矩阵中两列均为 Y）。
4. **Aura 新增特性（训练侧）**：
   - 支持「共卡模式」训练，对应用户指南 `./04_user_guide/02_hybrid.md`。
   - 支持「分离模式」训练，对应用户指南 `./04_user_guide/03_one_step_off.md`。
   - 支持 qwen3-4b、qwen3-8b、qwen3-32b、qwen3-30b-a3b 模型（4 个具体模型规模）。
5. **运行平台**：上述三项 Aura 新特性均以 "Atlas 900 A3 SuperPoD 训练服务器" 为配套产品型号。
6. **稳定性声明**：版本使用注意事项、升级过程影响、升级后影响、已解决问题、遗留问题、漏洞修补列表均标注为「无」。

## 【关键机制与数据】

- **产品-组件关系**：本版本主推 Aura 组件，「新增特性」「业务接口变更」「关键特性变更」三栏仅描述 Aura 一条组件线，提示 Aura 是本期面向训练场景的核心载体组件。
- **兼容性矩阵机制**：通过 Y/N 单元格表达「某 Agent SDK 版本是否经过某 CANN/HDK 版本官方验证」。本版本 26.1.0 在 CANN 9.0.0 / 9.1.0、HDK 26.0.RC1 / 26.1.0 四个交叉点上均为 Y，表示双重兼容。
- **训练模式机制**（基于原文命名）：文档将 Aura 训练能力区分为「共卡模式」与「分离模式」两种，按点击内链可知分别对应 `04_user_guide/02_hybrid.md` 与 `04_user_guide/03_one_step_off.md` 两份独立指南，说明两种模式具备独立的使用方式，不是同一机制的开关变体。
- **模型支持规模**：qwen3 系列支持 4b / 8b / 32b / 30b-a3b 共 4 档参数规模，其中 30b-a3b 为 MoE 架构命名（a3b 通常表示激活参数量），其余为稠密规模命名（原文未做此细分，标注此为命名释义而非原文断言）。
- **性能数据**：原文未提供任何吞吐量、时延、显存占用等性能数字，标注「原文无性能数据」。
