# Ascend NPU-Burn 26.1.0 Release Notes 深度解读

## 【定位】
本篇文档是 **Ascend NPU-Burn 26.1.0（首版 Release 版本）的版本配套说明与变更说明**，回答"该版本是什么、与哪些 CANN/TorchNPU 配套、是否兼容哪些硬件、新增了哪些故障压测特性、命令行工具如何发布"等问题。

---

## 【技术要点】
1. **产品形态**：Ascend NPU-Burn 26.1.0 为 Release 版本；同代 26.0 系列共规划 26.1.0 / 26.2.0 / 26.3.0 三个版本。
2. **核心新增能力 - SDC 检测**：算子用例通过**多次执行结果对比**，检测存在**静默数据损坏（Silent Data Corruption）** 的芯片设备；原文列表中该条目重复出现两次。
3. **核心新增能力 - 多算子压测用例集成**：覆盖 **AIC 计算单元 / AIV 计算单元 / Atomic 计算单元 / Fixpipe 量化单元 / CV 同步** 等多类计算/同步单元。
4. **核心新增能力 - 用例配置化**：可通过配置方式快速集成算子的 **dtype、shape、数据模式**。
5. **核心新增能力 - 多卡并行**：支持 **OS 域内多卡并行压测**。
6. **命令行接口 `npu-burn`**：**首版本发布**（无前序版本）。
7. **版本兼容性约束**：
   - CANN 9.0.0 + TorchNPU 26.0.0，或 CANN 9.1.0 + TorchNPU 26.1.0，两套组合均与 26.1.0 兼容（"Y"）。
   - 在 CANN 9.1.0 / TorchNPU 26.1.0 组合下，PyTorch **暂不支持 2.11.0、2.12.0**。
   - PyTorch 与 Python 版本均"与 TorchNPU 配套"（不单独指定）。
   - **CANN 9.0.0 不支持 Ascend 950 系列产品中的 Atlas 850 系列硬件产品、Atlas 950 SuperPoD**。
8. **配套文档**：Ascend NPU-Burn 用户指南（`./README.md`），涵盖介绍、前置知识、快速入门、安装、特性指南、API 参考、参考资料。
