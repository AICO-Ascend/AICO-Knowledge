# 「mindcluster-ascendnpuburn」Overview 文档深度解读

---

## 【定位】

本文档是 Ascend NPU-Burn 的总览章节,定位为「面向昇腾 NPU 芯片、覆盖硬件全生命周期、以高强度算子用例压测方式检测静默数据损坏（SDC）及硬件缺陷」的可靠性检测工具的能力宣示与价值总纲文档,解决「AI 硬件日益复杂、SDC 等隐性故障难以通过训练/推理失败被发现」的痛点问题。

---

## 【技术要点】

1. **检测对象——SDC(Silent Data Corruption,静默数据损坏)**:原文明确点出 SDC 不会引起训练/推理失败或性能下降,因此难以发现,这正是该工具的核心捕获目标。
2. **技术栈构成**:基于 **PyTorch + CANN 框架**实现,运行在昇腾 NPU 之上,通过在 NPU 上执行高强度算子用例持续施加**计算与带宽压力**。
3. **覆盖的计算/同步单元**(原文逐字列举):**AIC 计算单元 / AIV 计算单元 / Atomic 计算单元 / Fixpipe 量化单元 / CV 同步**,通过算子用例对这些单元进行覆盖式压测。
4. **硬件缺陷的捕获路径**:在高负载运行下,**硬件缺陷(例如计算单元异常)**所引发的静默数据损坏会被检出。
5. **用例可配置维度**:通过配置方式集成算子的 **dtype / shape / 数据模式**,实现用例的快速适配。
6. **并行能力**:支持 **OS 域内多卡并行压测**,即在同一操作系统域内对多张 NPU 卡并行施加压力。
7. **生命周期覆盖**:覆盖**产线阶段(全量严格检测)/ 商业阶段(开局加严测试)/ 故障阶段(量化故障评估)**三种部署阶段。
