# Driving SDK Introduction 深度解读

## 【定位】

本文档作为 Driving SDK 的总览性介绍，定位为昇腾 AI 集群系统下面向**自动驾驶领域**的训练加速套件入门指南，向行业客户与开发者说明 SDK 所提供的**底座能力**——即一套由"优选模型库 + 一键 Patcher + 高性能算子库 + 训练通用优化"四部分组成的端到端昇腾 NPU 适配与加速能力。

---

## 【技术要点】

1. **SDK 三大核心组件 + 一组通用能力**：架构包含「优选模型库」「一键 Patcher」「自动驾驶高性能算子库」三大组件，外加跨组件可复用的「训练通用优化」能力，形成一个完整的迁移-训练-调优闭环。
2. **模型覆盖范围**：覆盖端到端模型、BEV 感知、预测规划、OCC 感知、Lidar 感知、Lane&Map、VLA、世界模型八大方向；明确列举的典型模型包括 **UniAD、SparseDrive、BEVFormer、MapTR、OpenVLA、Cosmos**，且声明"部分模型经过深度优化后性能达到业界领先水平"。
3. **一键 Patcher 的 Monkey Patch 机制**：基于 Monkey Patch 实现 **CUDA → NPU 的零侵入迁移**——无需修改原始源代码，通过运行时动态替换即可完成适配；体现"零侵入"这一关键技术属性。
4. **Patcher 的四类子能力**：
    - **模型迁移**：通过 `skip_import / replace_import / inject_import` 三类导入控制 + 预定义补丁完成 CUDA 算子替换与第三方库适配；已内置 **mmcv、torch、numpy** 的 NPU 适配补丁，并支持自定义扩展。
    - **性能诊断**：内置 Profiling 工具，支持 **NPU / NPU+CPU / NPU+CPU+调用栈** 三档多层级采集，并可精确控制采集的迭代区间。
    - **训练调试**：提供 **训练早停（Brake）** 辅助功能，并与 Profiling 组合，实现"采集完自动停止"。
    - **通用优化使能**：把通算融合、低精训练等手段下发到客户自有模型。
5. **高性能算子库覆盖方向**：覆盖通用、采样、体素化、检测、稀疏、融合六大方向；典型算子列举为 **BEVPool、SparseConv3d、DynamicScatter、MultiScaleDeformableAttention、ScatterMean**。
6. **算子支持的硬件产品族**：明确标注支持 **Atlas A2 训练系列产品、Atlas A3 训练系列产品、Ascend 950 系列产品** 三类硬件。
7. **训练通用优化矩阵**：从训练策略、Host 侧执行到昇腾亲和优化三个维度展开，包含 **多机训练、通算融合、低精训练、负载均衡、二级流水下发、细粒度绑核、图模式、数据预处理优化、融合优化器、CV 融合、AIPP&DVPP** 等十余项能力。

---

## 【关键机制与数据】

**工作机制 1：Monkey Patch 零侵入迁移**
原文核心描述——"无需修改原始源代码，通过运行时动态替换即可完成适配"。这意味着迁移过程发生在 Python 运行时层（导入期/属性访问期），对用户仓库的 `.py`/`.cu` 文件保持只读，迁移成本与代码冲突风险大幅降低。

**工作机制 2：导入级精细控制三元组**
原文描述——"`skip_import / replace_import / inject_import`"。三者构成一个完整的"拦截-替换-注入"链路：
- `skip_import`：跳过某个原生模块的导入（例如跳过 mmcv 的 CUDA 后端）；
- `replace_import`：用 NPU 等价实现整体替换；
- `inject_import`：在保留原生模块的基础上，按需注入 NPU 算子扩展。
这一三元组是 Patcher 与"暴力重写源码"式迁移工具的本质区别。

**工作机制 3：Profiling 多层级采集 + Brake 联动**
原文描述——"支持多层级采集（NPU/NPU+CPU/NPU+CPU+调用栈），可精确控制采集的迭代区间"，并提供 Brake 实现"采集完自动停止"。该组合避免了大规模训练场景下"为了采 profile 不得不停掉整个任务"的操作断层。

**数据流（按原文表述还原）**：模型迁移流程为「用户 CUDA 源模型 → 一键 Patcher（导入控制 + Monkey Patch + NPU 补丁） → 昇腾 NPU 可执行模型 → 通过 Profiling 诊断 + Brake 控制 → 应用训练通用优化（通算融合/低精/融合优化器等） → 在 Atlas A2/A3/Ascend 950 上完成高性能训练」。

**性能数据**：原文未给出具体数字（如 FPS、加速比、训练耗时等），仅声明"部分模型经过深度优化后性能达到业界领先水平"，并将定量性能数据引向 `../models/support_list.md`。
