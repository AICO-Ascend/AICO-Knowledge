# 文档深度解读:Vision SDK 26.1.0 版本说明

## 【定位】
这篇 changelog是一份**版本配套与兼容性声明文档**,描述 Vision SDK 26.1.0(候选版本)的产品版本元信息、与底层 CANN/Ascend HDK 的版本配套关系、版本兼容性矩阵,以及本次版本相对上一版的功能/接口变更情况(本版无新增与变更)。

---

## 【技术要点】

1. **当前发布版本**:Vision SDK **26.1.0**(候选版本),维护周期 **3 个月**。
2. **配套软件版本**:Ascend HDK **26.1.0** + CANN **9.1.0**(必须三者齐平配套使用,见原文"表 1")。
3. **版本兼容性矩阵(纵向自洽)**:
   - Vision SDK 7.3.0 仅与 CANN 8.5.0 / HDK 25.5.0 兼容;
   - Vision SDK 26.0.0 与 CANN 8.5.0、9.0.0 / HDK 25.5.0、26.0.RC1 兼容;
   - Vision SDK 26.1.0 与 CANN 8.5.0、9.0.0、9.1.0 / HDK 25.5.0、26.0.RC1、26.1.0 全部兼容(向下全兼容)。
4. **本次变更结论**:新增特性、业务接口、关键特性、已解决问题、遗留问题、升级影响、漏洞修补——**全部为"无/不涉及"**,仅完成版本号对齐发布与文档配套更新。
5. **配套产品型号清单(适用平台)**:涵盖 Atlas 300I/300I Pro/300I Duo/300V/300V Pro、Atlas 500 A2 智能小站、Atlas 200I SoC A1 核心板、Atlas 800I A2 等共 9 类推理/视频解析硬件形态(x86_64、Arm 双架构)。
6. **安全合规状态**:病毒扫描通过;漏洞修补列表为空。

---

原文未涉及任何工作原理、数据流或性能数据(无新增特性章节意味着本次未引入新的算法/算子/性能调优项)。

### 表 2 Vision SDK 与 CANN 版本兼容

| Vision SDK \ CANN 版本 | 8.5.0 | 9.0.0 | 9.1.0 |
|---|---|---|---|
| 7.3.0 | Y | / | / |
| 26.0.0 | Y | Y | / |

**逐行解读**:
- **行 7.3.0**:旧版 SDK 仅与最旧的 CANN 8.5.0 配套,不兼容 9.0.0 及以上——回退到老栈部署时必须用 CANN 8.5.0。
- **行 26.0.0**:中间过渡版,兼容 CANN 8.5.0、9.0.0,但**尚未适配** 9.1.0。
- **行 26.1.0(本版本)**:对 CANN 8.5.0、9.0.0、9.1.0 三个版本**全部 Y**,体现"向下全兼容"特性——升级到 26.1.0 后,即便底层 CANN 仍停留在 8.5.0/9.0.0 也不需联动升级。
