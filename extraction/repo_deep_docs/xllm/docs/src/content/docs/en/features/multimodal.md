# 一体化深度解读：xLLM 多模态支持文档

---

## 【定位】

本篇文档概述 xLLM 推理引擎当前所支持的多模态能力，覆盖已适配的多模态模型清单、模态类型范围以及离线/在线两类接口的存在性说明，目标在于为使用者提供一份"能用什么模型、处理什么模态"的快速能力地图。

---

## 【技术要点】

1. **支持四款多模态模型系列**：覆盖 Qwen2.5-VL（7B/32B/72B）、Qwen3-VL（2B/4B/8B/32B）、Qwen3-VL-MoE（A3B/A22B）与 MiniCPM-V-2_6（7B），其中 Qwen3-VL-MoE 走的是 MoE 稀疏激活路线。
2. **当前模态仅以图像为主**：支持单图、多图输入、图像 + 文本提示组合、以及纯文本提示四种调用形式；视频、音频等其他模态标注为"in progress"（开发中）。
3. **图像输入支持 Base64 数据与图像 URL 两种编码/寻址方式**。
4. **ChatTemplate 统一改用 Jinja 渲染**：相较此前可能存在差异化的渲染方式，现统一在 Jinja 框架下执行；部署 MiniCPM-V-2_6 时需在模型目录中显式提供 ChatTemplate 文件。
5. **多模态后端尚未支持 prefix cache 与 chunked prefill**，两条特性均标注为"in progress"。
6. **接口层同时覆盖 offline（离线）与 online（在线）两类**，文档标题与导言均予以提及，但本篇正文未展开二者具体 API 形态。
