# MindStudio Debugger Release Notes 深度解读

## 【定位】

本文档是 **msDebug (MindStudio Debugger)** 调试器的版本发布说明 (changelog), 覆盖两个产品版本——**26.0.0 (内部测试版)** 与 **8.3.0 (首个官方版本)**, 系统性记录其与 makeself / libedit / ncurses 等关联组件的版本对应关系、版本兼容性结论, 以及 26.0.0 版本相对前一阶段在板级调试 / coredump 解析 / 编译构建 / 安装包标准化等方面新增的功能、删除项和缺陷修复。

---

## 【技术要点】

以下按"功能面 / 构建发布面 / 缺陷修复面"分条归纳核心机制, 保留原文中的关键命令与参数:

**功能 (Function) 面:**
1. **免设置内核对象路径的板级调试**——降低用户前置配置负担, 直接进入调试会话。
2. **内存读取时可跳过元素个数**——增强 `memory read` 类操作在大块数据浏览时的灵活性。
3. **shared_memory 算子场景调试支持**——覆盖共享内存算子的调试链路。
4. **ASC 编译算子的 coredump 调试 + 板级调试双支持**——对接 ASC (Ascend Software Compiler) 编译产物。
5. **Host → Kernel 传递结构体变量的打印支持**——打通跨域结构化数据可观测性。
6. **非内联 (non-inline) 编译模式下 coredump 解析的回溯调用栈能力**——在无内联符号的情况下也能重建调用栈。

**构建与发布 (Build and release) 面:**
7. **root 用户对安装目录的最小权限收紧为 `700`**——安全基线提升。
8. **GCC 7 / GCC 12 下 UT 编译失败的修复**——扩大编译器兼容性。
9. **安装包名称标准化**——交付物命名规范化。
10. **libtinfo 动态库编译期路径错误修复**——链接稳定性增强。
11. **新增交付物 `libform.so.5`**, 解决部分环境对该库的依赖。
12. **支持 Unix Makefiles 构建**——引入 CMake 的 `Unix Makefiles` 生成器。

**缺陷修复 (Bug Fixes) 面:**
13. `finish` 命令在某些场景下导致工具挂起的修复。
14. `ascend info cores` 命令在混合算子场景下输出多个 `*` 地址的修复。
15. `var` 命令打印 `uint8_t *` (如 `gm`) 变量时乱码的修复。
16. 若干函数的错误提示信息优化。

> 注: 8.3.0 作为首个官方版本, 仅定义了板级调试 (断点 / 变量 / 寄存器 / 内存 / 代码行级单步 / 核信息显示与切换 / 调用栈显示) 与 coredump 文件解析 (调用栈 / 寄存器 / 变量显示) 的最小能力集, 无新增缺陷修复条目。
