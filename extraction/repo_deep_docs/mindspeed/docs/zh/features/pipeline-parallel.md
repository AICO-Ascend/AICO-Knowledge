# Megatron 流水线并行 — 一体化深度解读

## 【定位】

这篇文档描述 Megatron 流水线并行（Pipeline Parallelism, PP）能力的背景、原理、适用场景、启用方式与使用效果，解决大模型训练中**单一计算设备无法承载整个模型的存储与计算需求**以及**传统模型并行下各设备间存在严重等待时间导致计算资源利用率低下**的问题。

---

## 【技术要点】

1. **阶段划分（Stage Partitioning）**：将整个神经网络模型分为多个逻辑阶段，每个阶段在不同的计算设备（原文为 NPU）上独立执行。
2. **接力式并行（Relay-style Parallelism）**：各阶段之间以前后接力方式执行，当前阶段的计算结果作为下一阶段的输入，形成连续的前向与反向计算流程。
3. **预热与冷却（Warm-up & Cool-down）**：训练开始时执行预热阶段以初始化计算流程；训练末尾执行冷却阶段以确保所有阶段计算任务全部完成。
4. **配置参数 `--pipeline-model-parallel-size N`**：N 表示流水线并行的阶段数，即参与并行训练的 NPU 数量，**默认值为 1**。
5. **理论来源**：核心机制参考论文 [PipeDream: Fast and Efficient Pipeline Parallel DNN Training](https://arxiv.org/pdf/1806.03377)。
6. **调度示意**：文档配图 **图1 流水线并行调度示意图**（对应文件 `figures/pipedream1F1B.png`），展示 1F1B 调度模式。

---

## 【关键机制与数据】

**工作原理（流水线执行流程）：**

- 流水线并行借鉴**工业生产中的流水线理念**，将模型划分为多个阶段并分配到不同计算设备上。
- 通过**接力式并行计算**实现前后阶段的衔接，以**最大程度减少设备间的等待时间**，同时**缩短前向与反向计算之间的距离**，从而**有效降低内存消耗**。
- 执行过程包含两个关键过渡期：
  - **预热（Warm-up）**：训练开始阶段用于初始化计算流程。
  - **冷却（Cool-down）**：训练末尾阶段用于收尾，确保所有阶段计算任务完成。

## 【使用方法】

在训练脚本中加入以下参数即可启用流水线并行：

```bash
--pipeline-model-parallel-size N      # N 表示流水线并行的阶段数，即参与并行训练的 NPU 数量
```

- **默认值为 1**（即不启用流水线并行）。
- 用户需根据实际硬件资源与模型规模配置 N 的取值。
- 原文未涉及其他相关配置项（如 micro-batch 数量、调度策略选择等）。
