# mindspeed 仓 QAT 量化文档深度解读

## 【定位】

这篇文档描述 mindspeed 面向大模型微调与训练场景引入的**QAT（Quantization-Aware Training）低精度量化能力**，通过在前向传播中模拟 MXFP4/MXFP8 格式的量化-反量化过程，使模型在权重仍以高精度（如 BF16）存储的前提下适配 W4A16 等低精策略，从而缓解大模型训练/微调的显存瓶颈。

---

## 【技术要点】

1. **核心策略：W4A16 低精适配**。权重在前向时被量化为 MXFP4（E2M1+块缩放）再反量化回高精度参与计算，反向借助 STE（梯度直通估计）使梯度更新原始高精度权重。
2. **存储-计算分离**：权重仍以 BF16 等高精度存储和更新，仅在计算时引入量化误差，实现"训练感知量化、推理低成本"的桥梁。
3. **量化格式支持**：提供两种 MX 家族格式——MXFP4（4 位浮点，E2M1+块缩放）与 MXFP8（8 位浮点）。
4. **作用范围可粒度化**：可选择"所有线性层"或"仅 MOE 层"作为量化作用对象，二者通过 CLI 后缀 `-moe-only` 区分。
5. **四种 CLI 启用方案**（须在训练脚本中传入）：
   - `--qat-scheme w4a16-mxfp4`：所有线性层启用 MXFP4 量化
   - `--qat-scheme w4a16-mxfp4-moe-only`：仅 MOE 层启用 MXFP4 量化
   - `--qat-scheme w8a16-mxfp8`：所有线性层启用 MXFP8 量化
   - `--qat-scheme w8a16-mxfp8-moe-only`：仅 MOE 层启用 MXFP8 量化
6. **隐式默认行为**：除上述四种显式配置外的其他设置（或不设置）均走"原始策略"（即不启用 QAT 量化）。

---

## 【关键机制与数据】

**工作原理（原文: "针对微调和训练场景，通过模拟MXFP4格式的量化-反量化过程引入量化误差，但权重仍以高精度（如BF16）存储和更新"）**：

- 前向传播路径：原始高精度权重 → 量化到 MXFP4（E2M1+块缩放格式）→ 反量化回高精度 → 参与下游计算。量化-反量化这一过程在前向图中显式存在，是引入"模拟量化误差"的来源。
- 反向传播路径（原文: "反向传播则通常借助梯度直通估计（STE），使梯度能有效更新原始权重"）：由于量化操作不可微，STE 把量化算子的梯度近似为恒等映射，从而让梯度穿过量化节点直接回流到原始的高精度 BF16 权重上。
- 目的（原文: "从而适配W4A16的低精策略"）：训练阶段并未真正以 4-bit 权重存储，而是让模型"习惯"低精推理时的精度损失，便于后续部署到 W4A16 推理路径。

**性能数据**：原文未给出任何具体数值（无加速比、无显存节省、无精度对比表），仅以一句"精度损失控制在可接受范围"做定性结论。

## 【使用方法】

原文明确给出以下启用方式（须添加到训练脚本中）：

| 编号 | 作用范围 | 量化格式 | 配置项 |
|------|---------|---------|--------|
| 1 | 所有线性层 | MXFP4（E2M1+块缩放） | `--qat-scheme w4a16-mxfp4` |
