# Megatron 张量并行 — 一体化深度解读

## 【定位】
这篇文档介绍 Megatron 张量并行（Tensor Parallelism, TP）这一模型并行实现方式，说明其如何将模型参数矩阵切分到多台计算设备上以突破单机内存与算力瓶颈。

---

## 【技术要点】

1. **问题驱动**：单一计算设备的内存容量与算力无法承载日益膨胀的模型尺寸，导致训练周期拉长，需要跨设备切分模型实现并行存储与计算。
2. **两类切分策略**：
   - **参数矩阵横切**：按参数矩阵**行方向**切分，输入矩阵需相应按**列方向**切分。
   - **参数矩阵纵切**：按参数矩阵**列方向**切分，输入矩阵**无需切分**。
3. **横切前向**：各切分后的输入矩阵进入对应模型部分独立计算，再通过 **AllReduce** 汇总各部分结果得到最终输出。
4. **横切反向**：将最终输出梯度按比例分配给各部分模型输出梯度，通过 **AllGather** 合并各切分输入矩阵的梯度，恢复初始输入矩阵梯度。
5. **纵切前向**：将完整输入矩阵送入各部分模型独立计算，通过 **AllGather** 拼接各部分输出形成最终输出。
6. **纵切反向**：将最终输出梯度按比例切分并传递，再通过 **AllReduce** 汇总各部分输入矩阵梯度，得到初始输入矩阵梯度。

---

## 【关键机制与数据】

**工作原理与数据流**（基于原文描述）：

- **横切策略**本质上要求通信操作在计算**之后**做一次 **AllReduce**（前向），在反向时再做一次 **AllGather**——也就是说每个切分块在前向结束后才"看到"其它切分块的结果。
- **纵切策略**与横切互为对偶：前向使用 **AllGather** 聚合输出，反向使用 **AllReduce** 聚合输入梯度。
