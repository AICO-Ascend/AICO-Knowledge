# Flash Attention

## 【定位】

本文介绍 Flash Attention 如何通过优化 IO 访存，在保持精确注意力计算的同时，降低 Transformer 处理长序列时的计算时间和内存开销。

## 【技术要点】

1. **核心问题**：Self-Attention 的时间与空间复杂度随序列长度呈平方增长，长序列输入会显著增加计算时间和内存消耗。
2. **方案性质**：Flash Attention 是优化 IO 访存开销的**精确注意力方法**，并非通过降低计算精度、稀疏注意力或替代注意力模式来近似加速。
3. **IO 优化目标**：通过减少高带宽内存（片上内存）与 SRAM 之间的数据读写次数，降低长序列注意力计算的时间和内存压力。
4. **三类关键机制**：
   - **Tiling 切片**：使用容量较小但速度更快的 SRAM 分块完成注意力计算，避免一次性装入全部数据。
   - **重计算**：不将中间结果写回，需要时重新生成，以额外计算换取更少的访存。
   - **Kernel Fusion**：融合多个操作，并基于 Tiling 使用一个 kernel 完成整个注意力计算。
5. **启用与效果**：使用 `--use-flash-attn` 调用；原文称在 **Llama-2-7b** 模型上性能提升约 **34%**。

## 【关键机制与数据】

- **原文：**传统 Self-Attention 在处理长序列时，时间与空间复杂度均随序列长度呈平方增长，计算时间和内存消耗会显著增加。
- **原文：**近似注意力通常通过牺牲计算精度、实施稀疏注意力或引入替代注意力模式来降低复杂度，但可能造成模型质量折损。
- **原文：**Flash Attention 的整体目标是保留精确注意力计算，同时减少高带宽内存（片上内存）与 SRAM 之间的数据读写。
- **原文：**由于 SRAM 容量较小，无法一次完成全部注意力计算，因此需要将数据切分为块，并在 SRAM 中分块处理。
- **原文：**中间结果不再写回高带宽内存；后续需要时通过重计算恢复，从而以计算开销换取更少的内存读写。
- **原文：**多个注意力操作被融合进一个 kernel，并结合 Tiling 完成整体计算，以减少操作间潜在的访存。
- **原文：**该方法尤其适用于长序列输入场景；开启长序列并行时，该特性默认开启。
- **原文：**在 **Llama-2-7b** 模型下，使用 Flash Attention 后性能提升约 **34%**。原文还定性表示可以提升模型训练效率并节省训练内存，但未给出内存节省比例或其他性能指标。
