## 【技术要点】

1. **核心定位**：面向多模态大模型推理**预处理流程**的昇腾亲和性加速 SDK，不涉及模型推理本身。
2. **覆盖操作范围**：包含图像/视频加载、解码（load & decode），以及 resize、crop 等常见预处理算子。
3. **数据结构互转**：支持多种**开源数据结构**（如 PyTorch/transformers 等）与**昇腾加速库数据结构**（如 CANN ACL 相关的张量/图片格式）之间的相互转换，目的是"方便快速使用和移植"。
4. **框架级插件**：以 vLLM 框架预处理插件（preprocessing plugin）形态集成，提供端到端加速路径，而非独立 CLI 工具。
5. **模型适配范围（vLLM 插件内）**：目前明确点名两个模型——**Qwen2VL** 与 **InternVL2**，均为图像/视频预处理加速。
6. **加速库抽象层**：底层提供"一系列高性能图像和张量处理接口"，作为上层 vLLM 插件和上层调用的算力底座。

## 【使用方法】

本文档**未给出 SDK 的启用、配置或调用命令**，仅在硬件章节中提供两条**设备信息查询命令**（用于查询环境是否满足前置条件，非 SDK 自身命令）：

```bash
# 方式一：使用 dmidecode 查询设备产品型号
dmidecode -s system-product-name

# 方式二：读取 sysfs 文件查询设备产品型号
cat /sys/class/dmi/id/product_name
```

**说明**：
- 两条命令返回内容为系统产品名称字符串，用于**事前确认硬件型号是否在受支持列表中**，与 SDK 的安装、初始化、调用无关。
