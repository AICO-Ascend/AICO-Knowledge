# MultimodalSDK 26.1.0 版本说明深度解读

## 【定位】

本文档是 MultimodalSDK **26.1.0** 版本的官方 Release Notes（变更日志），用于说明该版本的版本配套关系、与 CANN/Ascend HDK 的兼容性矩阵、新增特性清单及配套文档索引，属于版本发布维度的元信息文档，不涉及具体 API 调用细节。

---

## 【技术要点】

1. **关键帧筛选能力**：新增 `KFrameSelector` / `KRangFrameSelector` 两个类，基于文本-图像相似度从视频中筛选与查询相关的离散关键帧；额外支持识别连续场景区间并在区间内做自适应重采样，覆盖通用视频问答与目标出现时间定位场景。
2. **Video RAG 视频理解参考设计**：新增"自动寻优与多尺度重采样"示例，整合视频帧提取、音频提取、ASR、OCR、目标检测、语义检索、检索重排序、Prompt 组装全链路，具备自适应关键帧选择、均匀采样回退与音频重采样能力，面向长视频问答的上下文召回与生成。
3. **视觉 Token 压缩参考设计**：在 `vllm-ascend` 框架下，针对 `Qwen2.5-VL` 提供 SCC（Semantic Connected Components）视觉 token 压缩服务端补丁，按语义相似度聚合视觉 embedding 并同步调整 image/video placeholder 数量，目标是在保持模型效果前提下降低视觉 token 数、提升多模态推理吞吐。
4. **版本配套基线**：本次 Release 与 Ascend HDK 26.1.0、CANN 9.1.0 同步发布，并向下兼容 CANN 9.0.0、Ascend HDK 26.0.RC1。
5. **运行载体**：三项新增特性均标注配套 **Atlas 800I A2 推理服务器**。
6. **业务接口/关键特性变更**：本版本均标注"无"变更；亦无遗留问题、无漏洞修补、无升级影响。

## 【关键机制与数据】

- **版本兼容矩阵数据**（原文）：
  - Multimodal SDK 26.0.0 ↔ CANN 9.0.0 = Y；↔ CANN 9.1.0 = /
  - Multimodal SDK 26.1.0 ↔ CANN 9.0.0 = Y；↔ CANN 9.1.0 = Y
  - Multimodal SDK 26.0.0 ↔ Ascend HDK 26.0.RC1 = Y；↔ Ascend HDK 26.1.0 = /
  - Multimodal SDK 26.1.0 ↔ Ascend HDK 26.0.RC1 = Y；↔ Ascend HDK 26.1.0 = Y
  - 注："Y"代表可配套，"/"代表不可配套（原文 NOTE 标注）。
- **特性 1（关键帧筛选）工作机制**（原文）：以"文本-图像相似度"为筛选准则，先输出离散相关关键帧，再进一步识别"连续场景区间"并在该区间内做"自适应重采样"，构成"点选 + 区段重采样"两级机制。
- **特性 2（Video RAG 参考设计）数据流**（原文，按出现顺序）：视频帧提取 → 音频提取 → ASR → OCR → 目标检测 → 语义检索 → 检索重排序 → Prompt 组装；并以自适应关键帧选择、均匀采样回退、音频重采样三种策略协同。
- **特性 3（SCC 视觉 token 压缩）工作机制**（原文）：以"语义相似度"为聚合准则，将视觉 embedding 按 SCC 方式聚合；同时同步调整 image/video placeholder 数量；目标是"降低视觉 token 数量、提升多模态推理吞吐"，且"尽量保持模型效果"。
- **性能/吞吐数据**：原文未给出任何量化性能指标（如具体 token 压缩比、QPS、时延等），故不臆造。
- **病毒扫描**：原文声明"病毒扫描通过"，无安全告警项。
