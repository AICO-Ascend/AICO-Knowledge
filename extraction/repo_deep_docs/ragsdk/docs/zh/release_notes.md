# RAG SDK 26.1.0 版本说明 — 一体化深度解读

## 【定位】
本文档是 RAG SDK 26.1.0 版本的 Release 版本 changelog（版本说明），用于声明本发行版的产品身份、与上下游软件栈（CANN、Ascend HDK、MindSDK）的版本配套/兼容关系、本版本新增的业务特性、业务接口与关键特性的变更情况、升级影响以及配套文档入口。

---

## 【技术要点】

1. **本版本核心定位**：RAG SDK 产品版本 **26.1.0**，版本类型为 **Release 版本**（原文："产品版本: 26.1.0 / 版本类型: Release版本"）。
2. **推荐配套组合**：本版本强制/推荐的运行环境为 **CANN 9.1.0 + Ascend HDK 26.1.0**（原文：表 1 RAG SDK软件版本配套表）。
3. **向下兼容范围**：本版本对 CANN 8.5.0 / 9.0.0 / 9.1.0、Ascend HDK 25.5.0 / 26.0.RC1 / 26.1.0、MindSDK 7.1.RC1 / 7.2.RC1 / 7.3.0 全部标 "Y"（可配套）；而 26.0.0 版本对 CANN 9.1.0、HDK 26.1.0、MindSDK 7.3.0 标 "/"（不可配套）。
4. **本版本唯一新增特性**：bge 系列 embedding 和 reranker 加速，对 **bge-reranker-v2-m3** 和 **bge-m3** 两个模型做了性能优化（原文："bge系列embedding和reranker加速，bge-reranker-v2-m3和bge-m3模型性能优化"）。
5. **新增特性的硬件载体**：仅声明配套 **Atlas 300I Duo 推理卡** 与 **Atlas 800I A2 推理服务器** 两款昇腾产品（原文表"新增特性"配套产品型号列）。
6. **变更清单状态**：业务接口变更、关键特性变更、已解决问题、遗留问题、升级影响、漏洞修补——全部标记为"无 / 不涉及"。
