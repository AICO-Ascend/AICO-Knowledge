## 【定位】

本文概述 🧨 Diffusers 的统一组件加载能力：通过 `from_pretrained()` 从 Hugging Face Hub 或本地机器加载生成任务所需的管道、模型和调度器，并说明后续内容将覆盖各类组件、变体、社区管道、调度器取舍及 KerasCV 检查点转换与加载。

## 【技术要点】

1. **统一加载入口**  
   🧨 Diffusers 提供单一集成方法 `from_pretrained()`，用于加载各种生成任务相关的管道、模型和调度器，避免为不同组件采用彼此分散的加载方式。

2. **支持两种组件来源**  
   组件既可以从 Hugging Face Hub 获取，也可以从本地机器加载。

3. **自动下载与缓存机制**  
   每次加载管道或模型时，最新文件都会自动下载并进入缓存；后续使用时无需再次下载相同文件，从而可以更快地复用。

4. **加载对象的范围**  
   本节围绕以下加载场景展开：
   - 完整管道；
   - 管道中的不同组件；
   - 检查点 variants；
   - 社区管道；
   - 调度器。

5. **调度器选择存在速度与质量权衡**  
   文档将说明如何加载不同调度器，并比较使用它们时产生的速度与质量之间的权衡，但原文没有给出具体调度器、性能数值或测试条件。

6. **跨框架检查点支持**  
   文档还计划介绍如何将 KerasCV 检查点转换为可在 PyTorch 中与 🧨 Diffusers 配合使用的形式并完成加载。

## 【关键机制与数据】

**Hugging Face Hub／本地机器 → `from_pretrained()` → 管道、模型或调度器 → 自动下载最新文件 → 缓存 → 下次直接复用**

## 【使用方法】

- 加载管道、模型或调度器时，使用统一入口：

```python
from_pretrained()
```

- 可将 Hugging Face Hub 或本地机器作为组件来源。
- 加载管道或模型后，文件会自动下载并缓存，后续无需再次下载相同文件。
