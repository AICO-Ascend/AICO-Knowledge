# MindStudio Kernel Launcher (msKL) 版本说明 深度解读

---

## 【定位】

本文档是 **MindStudio Kernel Launcher (msKL)** 的版本发布说明 (Release Notes), 用于记录并说明 msKL 产品各版本的配套关系、兼容性、特性变更、已知问题与废弃接口, 面向使用 msKL 进行算子调用、调测与性能调优的开发者提供版本层面的参考依据。

---

## 【技术要点】

1. **双版本并行发布**: 本次涉及两个产品版本——`msKL 26.0.0` (内测版本) 与 `msKL 8.3.0` (正式版本), 两者并行存在, 适用不同发布阶段。
2. **依赖配套**: `msKL 26.0.0` 推荐搭配 `CANN 9.0.0 及以上` 与 `Python 3.11 及以上`; `msKL 8.3.0` 要求 `CANN 8.2.RC1 及以上` 与 `Python 3.11 及以上`。
3. **核心调用接口**: `8.3.0` 首次发布并提供 `tiling_func` 与 `get_kernel_from_binary` 两个接口, 用于调用 msOpGen 工程中的 tiling 函数以及用户自定义的 Kernel 函数。
4. **自动调优能力**: `8.3.0` 提供 `autotune` 系列接口, 可对模板库算子进行 **代码替换 → 编译 → 运行 → 性能对比** 的全流程调优。
5. **版本性质差异**: `26.0.0` 为维护版本, 主要为稳定性改进和问题修复, 无新增对外特性; `8.3.0` 为首次发布版本, 含功能新增。
6. **兼容性与废弃情况**: 无兼容性变更, 无已知问题, 无废弃接口 (原文标注)。

## 【关联】

基于原文中明确提及的模块与接口:

- **msOpGen 工程**: `tiling_func` 与 `get_kernel_from_binary` 接口用于调用 **msOpGen 工程** 中的 tiling 函数, 说明 msKL 与 msOpGen (MindStudio Operator Generator, 算子生成工程) 之间存在调用依赖关系, msKL 充当算子调用层的入口。
- **CANN (Compute Architecture for Neural Networks)**: 版本配套表显示 msKL 必须与 CANN 共同使用, CANN 提供底层编译与运行时支持, msKL 位于其之上的算子调用与调测层。
- **模板库算子**: `autotune` 系列接口作用的运算对象为"模板库算子", 说明 msKL 与昇腾模板算子库存在直接交互。
- **用户自定义 Kernel**: `get_kernel_from_binary` 支持"用户自定义的 Kernel 函数", 表示 msKL 对第三方/用户态 Kernel 二进制同样开放调用通路。
- **Python 运行时**: 配套表显示 Python (3.11+) 为推荐依赖, 表明 msKL 提供 Python 绑定接口, 调用方可通过 Python 侧使用其能力。
