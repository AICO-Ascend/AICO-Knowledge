## 【定位】

本文档是「Faiss NPU」项目的总览性介绍文档，解决「在昇腾 NPU 硬件上提供与原版 Meta Faiss 完全兼容、且具备硬件加速能力的向量检索方案」的认知与选型问题，向读者说明项目定位、核心能力、软件架构以及已验证的硬件/操作系统组合。

## 【技术要点】

1. **完全兼容 Meta Faiss**：保留原版所有功能和 API 接口，支持 CPU 版本代码无缝迁移到 NPU。
2. **AscendC 自定义算子**：通过自研的 AscendC 自定义算子针对昇腾 NPU 硬件特性做深度优化，将核心距离计算（内积、L2 距离等）放在 NPU 上高效执行。
3. **多平台架构支持**：同时支持 ARM 和 x86_64 架构，已适配昇腾 910B 等芯片系列。
4. **多索引类型**：支持 Flat 等多种索引类型（原文显式列举 IndexFlat、IndexIVF、IndexHNSW 等 API 形态）。
5. **精度与数据规模**：支持 Float16 精度计算；面向大规模场景，支持高达亿级的向量检索。
6. **检索能力扩展**：支持批量检索和分页检索，并提供 NPU 资源管理与内存优化机制以优化大规模数据处理。

## 【关键机制与数据】

- **整体工作流（原文架构图描述）**：上层 Faiss API Layer（IndexFlat、IndexIVF、IndexHNSW 等）保持统一接口；下层按硬件后端分叉为三路实现——CPU Impl、GPU Impl、NPU Impl；其中 NPU Impl 下沉到 AscendC Ops 层完成实际算子执行。
- **核心距离计算路径（原文）**：使用 AscendC 自定义算子实现核心距离计算，包含**内积、L2 距离**等距离度量。
- **精度机制（原文）**：支持 **Float16** 精度计算，原文表述为「在保证精度的同时提升性能」。
- **资源管理机制（原文）**：提供 NPU 资源管理和内存优化机制。
- **检索模式（原文）**：支持批量检索和分页检索。
