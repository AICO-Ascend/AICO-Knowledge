# 虚拟流水线并行 深度解读

## 【定位】

本文档描述 Megatron 虚拟流水线并行（VPP, Virtual Pipeline Parallel）能力：在不增加设备数量的前提下，将同一流水线并行组再细分为多个"虚拟阶段"交错调度，以更多通信开销换取更小的流水线空泡（bubble）比率。

---

## 【技术要点】

1. **问题来源**：经典 PipeDream 流水线并行的切分粒度过粗，调度过程中仍残留较多空泡（bubble），计算资源利用率存在提升空间。
2. **核心思路**：在设备数量不变的情况下，通过引入"虚拟阶段"对模型层数做更细的切分，形成更多流水线阶段数；本质是用 **额外的跨阶段通信量** 换取 **更低的空泡比率**。
3. **阶段数计算**：`实际阶段数 = pipeline_parallel_size × virtual_pipeline_parallel_size`，每阶段层数 = 模型总层数 / 实际阶段数。
4. **交错调度**：前向不再只是单趟 `device 0 → 1 → 2 → 3`，而是按虚拟阶段顺序在设备间往返多次（文档示例为两趟 `0→1→2→3→0→1→2→3`），使各设备上的微批次（micro-batch）交叠执行，缩短首末气泡。
5. **配置开关**：通过 CLI 参数 `--num-layers-per-virtual-pipeline-stage N` 指定每个虚拟阶段的层数 N；启用条件为 **模型总层数 L 必须满足 `L % N == 0`**。
6. **权重兼容性约束**：VPP 会改变权重的切分（sharding）方式，因此 checkpoint 的保存/加载必须保证 VPP（以及 PP）配置一致，否则无法正常加载权重。

---

## 【关键机制与数据】

### 工作原理（原文示例数据）

| 项目 | 数值（原文示例） |
|---|---|
| 模型总层数 L | 16 |
| 张量并行大小（TP） | 1 |
| 流水线并行大小（PP） | 4 |
| 虚拟流水线并行大小（VPP） | 2 |
| 实际阶段数 | 4 × 2 = 8 |
| 每阶段层数 | 16 / 8 = 2 |

**设备—虚拟阶段—层的映射（原文逐字）**：

```
Device 0: [1, 2]  [9, 10]
Device 1: [3, 4]  [11, 12]
Device 2: [5, 6]  [13, 14]
Device 3: [7, 8]  [15, 16]
```

**前向顺序（原文）**：`device 0 → device 1 → device 2 → device 3 → device 0 → device 1 → device 2 → device 3`。

即每个物理设备承担两个不连续的虚拟阶段（间隔式排布），形成两趟流水线，使首末两端设备在第一趟尚未完成时即可启动第二趟对应的层，从而压缩流水线起泡与排空气泡。

## 【公式解读】

原文未给出标准 LaTeX 公式，仅含以下算术表达与约束，逐字保留如下：

1. **实际阶段数**  
   `$4 \times 2 = 8$`（原文："4 * 2 = 8"）  
   - 符号含义：`4` 为流水线并行大小 PP，`2` 为虚拟流水线并行大小 VPP，二者相乘得到模型被切分出的虚拟阶段总数。本例中 8 个阶段即 8 次独立的"层块"。

2. **每阶段层数**  
   `$16 / 8 = 2$`（原文："16 / 8 = 2"）  
   - 符号含义：分子 `16` 为模型总层数 L，分母 `8` 为上一步得到的虚拟阶段总数，结果 `2` 即每个虚拟阶段承载的层数 N。

3. **启用约束**  
   `$L \% N == 0$`（原文："`L % N == 0`"）  
   - 符号含义：`L` 为模型总层数（L_num_layers），`N` 为 `--num-layers-per-virtual-pipeline-stage` 的取值，`%` 为取余运算。该约束保证总层数可被每阶段层数整除，从而均匀切分到所有虚拟阶段。

## 【使用方法】

**启用方式（原文逐字）**：

```
--num-layers-per-virtual-pipeline-stage N
```

- `N` 表示每个虚拟阶段的层数。
- **前置约束**：模型总层数 L 必须满足 `L % N == 0`。
- **典型示例参数组合**（原文给出）：`--tensor-model-parallel-size 1`、`--pipeline-model-parallel-size 4` 配合 VPP=2，使 16 层模型被切成 8 个虚拟阶段、每阶段 2 层。
- **使用效果**：空泡比率进一步减小（原文仅作定性表述，未给出数值）。
- **注意事项**：保存与加载权重时必须保持 VPP（以及 PP）配置一致，否则权重无法正常加载。
