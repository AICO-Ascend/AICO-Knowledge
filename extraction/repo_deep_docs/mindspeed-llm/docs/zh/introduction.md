## 【技术要点】

1. **框架定位与对接关系**：MindSpeed LLM 是 MindSpeed 体系下的 LLM 分布式训练框架，**原生对接 MindSpeed Core 训练加速库**，专面向昇腾硬件，从**并行优化、内存优化、通信优化、计算优化**四个维度对大模型训练做加速。

2. **模型覆盖广度**：支持基于 Transformer 的多种 LLM（**Dense 模型与 MoE 模型**），内置**超过 100 个**主流开源模型及开箱即用训练脚本，覆盖**Qwen3 / DeepSeek / Mamba2** 等系列，涵盖 **Dense / MoE / SSM** 等架构，兼容基于 **Transformer / SSM** 架构的 LLM。

3. **双训练后端并行接入**：
   - **Megatron 训练后端**：以 **Megatron-LM** 为基座，提供以 **ModelSpec** 为模板的模型增量开发方案，支持**以周或天为单位**完成新模型开发。
   - **FSDP2 训练后端**：以 **MindSpeed-FSDP** 为基座，提供直接接入 **Transformers 第三方库**的模型增量开发方案，支持**以天为单位**完成新模型开发。

4. **多维分布式并行策略**：分布式预训练包含数据处理与主流模型/数据切分方案，明确列出 **TP / PP / DP / CP / EP** 等多维并行策略；指令微调支持**全参微调 / LoRA 微调**两类业界主流算法。

5. **功能模块完备性**：包含 **Megatron ↔ HuggingFace 权重转换**、分布式评估/推理、Profiling 数据采集、确定性计算、训练断点续训、训练最终权重保存；LoRA 微调权重支持**独立 / 合并**两种转换方式。

6. **在线推理与评估**：支持模型分布式在线推理，并提供基于**公开数据集与标准评测集**的在线评估能力，构成"训练—推理—评估"闭环。

## 【关键机制与数据】

- **四层架构纵向贯通**（原文：架构图描述）：自下而上为「**模型支持**（100+ 开源模型 / Transformer·SSM 架构）→ **训练流程**（分布式预训练 + 分布式指令微调）→ **训练后端**（Megatron 后端 / FSDP2 后端）→ **功能模块**（权重转换、评估/推理、Profiling、确定性、续训、权重保存）」，构成端到端的能力堆栈。

- **加速链路**：MindSpeed LLM **原生对接** MindSpeed Core 训练加速库（原文用"原生对接"表述），由后者在四个优化维度（并行、内存、通信、计算）上提供加速能力——这一对接关系是性能保证的关键路径。

- **MICROSOFT-style 增量开发节奏**（原文："支持以周或天为单位完成新模型开发"）：Megatron 后端通过 ModelSpec 模板、**FSDP2 后端通过直接接入 Transformers**，二者均定位为快速接入新模型，反映两种工程路线对开发效率的不同权衡。

- **LoRA 权重的两种转换形态**（原文："LoRA 微调权重的独立/合并转换"）：支持将 LoRA 增量权重**独立保存**或**合并到基座权重**两种形式，便于下游推理与分发。
