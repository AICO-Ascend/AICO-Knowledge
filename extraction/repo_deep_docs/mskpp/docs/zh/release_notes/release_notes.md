---

## 【定位】

本文档是 **MindStudio Kernel Performance Prediction (msKPP)** 的**首个正式版本 (8.3.0)** 的版本说明，宣告产品首次发布并对外明确其四大初始能力，以及运行所依赖的 CANN、Python、plotly 配套版本边界。

## 【技术要点】

1. **产品首次发布**：msKPP 8.3.0 为"正式版本"，类型标注为首次发布 (原文: "首次发布，新增功能点如下")，意味着本文档同时承担"功能清单"与"配套说明"双重作用。
2. **算子特性建模 (特性 ①)**：基于 msKPP **提供的接口**模拟出**算子耗时**——属于性能仿真 (simulation) 而非真实执行，输出为耗时模型。
3. **算子计算搬运规格分析 (特性 ②)**：生成两类统计文件——**搬运流水统计文件** 与 **指令信息统计文件**，用于回看建模结果。
4. **极限性能分析 (特性 ③)**：生成两类可视化——**指令流水图** 与 **指令占比饼图**，同样用于回看建模结果。
5. **算子 tiling 初步设计 (特性 ④)**：以"快速筛选几种较优 tiling 策略"为目标，定位在**初步设计 / 候选筛选**阶段，而非自动寻优闭环。
6. **配套依赖三件套** (原文硬性约束)：
   - CANN **8.2.RC1 及以上**
   - Python **3.9 及以上**
   - plotly **5.11.0 及以上**

> 补充事实：版本兼容性章节明确标注"无兼容性变更"；删除章节标注"无相关删除变更"；Bugfix 章节标注"无相关 Bugfix 变更"——三项均为空集。
