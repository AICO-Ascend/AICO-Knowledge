## 【定位】

本文介绍 `mindspeed-mm` 中基于参数名关键词的差异化学习率缩放与权重衰减排除能力，用于解决多模态大模型各模块因对 LR/WD 敏感度不同而无法使用全局统一优化配置的问题。

## 【技术要点】

- 面向 VLM 等包含视觉编码器、语言解码器的多模态模型，对不同参数实施参数级优化配置。
- 通过 `--weight-decay-exclude-modules` 指定参数名关键词，使命中的参数不参与权重衰减；示例关键词为 `norm`、`bias`。
- 通过 `--lr-scale-modules` 指定需要缩放学习率的参数名关键词；示例为匹配视觉模块的 `vision`。
- 使用 `--lr-mult` 设置学习率缩放乘数，原文示例为 `0.5`。
- 参数名匹配采用大小写不敏感的字符串匹配，因此不同大小写形式的关键词可命中相同参数。
- 两项能力默认关闭，必须在模型启动 shell 训练脚本中显式加入对应参数。

## 【关键机制与数据】

- **原文：** 启动训练时，在 `GPT_ARGS` 中传入模块关键词、LR 缩放关键词和缩放乘数。示例为：
  - 使用 `norm`、`bias` 匹配需要排除 WD 的参数；
  - 使用 `vision` 匹配需要差异化调整 LR 的视觉模块参数；
  - 使用 `0.5` 作为学习率乘数。
- **原文：** 匹配逻辑以参数名为对象进行关键词匹配，并且不区分关键词大小写。
- **原文：** WD 排除和 LR 缩放是两个独立的参数级控制入口：前者改变指定参数是否受 WD 影响的配置，后者对指定参数应用自定义 LR 乘数。
- **原文：** 该机制的目的包括降低统一 LR/WD 配置造成部分模块欠拟合或过拟合的风险，并改善多模态对齐和最终模型性能。
- **性能数据：** 原文未提供训练速度、显存占用、损失、精度或最终模型性能等实测数据。

## 【使用方法】

在模型启动 shell 训练脚本的 `GPT_ARGS` 中加入以下配置；所有参数仅用于展示配置方式，需按实际需要修改：

```shell
GPT_ARGS="
    ...
    --weight-decay-exclude-modules norm bias \ # 排除指定参数的权重衰减，根据实际需要设置参数关键词
    --lr-scale-modules vision \  # 对视觉模块参数缩放学习率（如mult=0.5）
    --lr-mult 0.5 \
"
```

其中：

- `--weight-decay-exclude-modules norm bias`：匹配参数名中包含 `norm` 或 `bias` 关键词的目标参数，并对其排除权重衰减。
- `--lr-scale-modules vision`：匹配参数名中包含 `vision` 关键词的目标参数。
- `--lr-mult 0.5`：为命中的参数设置学习率缩放乘数。
- 上述特性默认关闭，原文未涉及通过环境变量、配置文件或默认参数启用。
