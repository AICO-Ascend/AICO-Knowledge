# 一体化深度解读：模型结构提取特性设计说明书（fast_ops_grapher）

## 【定位】

本设计说明书描述 `fast_ops_grapher` 模块——一个面向 PyTorch 模型的计算图提取基础能力模块，定位是为 msModelSlim 量化压缩工具链提供算子级别的计算图可视化与分析能力，支持多种模型类型（自定义 nn.Module、HuggingFace Transformers、自动加载的 Transformers 模型）的图提取与多格式输出（原文）。

## 【技术要点】

1. **四大组成部件**：模块由 `Extractors`（从不同模型提取计算图）、`Exec Observer`（执行时观察器，捕获算子调用并构建图）、`Formatters`（格式化输出）、`ComputationGraph`/`GraphNode`/`GraphEdge`（计算图核心数据结构）组成（原文）。

2. **三种 Extractor 实现**：
   - `NativeModuleExtractor`：从任意 `nn.Module` 提取（原文示例）
   - `TransformerExtractor`：从已加载的 Transformers 模型提取，需传入 model + tokenizer（原文示例）
   - `TransformerAutoExtractor`：从模型路径自动加载并提取，支持 `trust_remote_code` 参数（原文示例 `meta-llama/Llama-2-7b-hf`）

3. **统一工厂方法 + 提取方法**：所有 Extractor 提供静态工厂方法 `create(...)` 与主提取方法 `extract_dag()`，返回 `ComputationGraph` 对象（原文）。

4. **图结构核心类**：`ComputationGraph` 继承自 `networkx.DiGraph`；`GraphNode` 代表算子节点；`GraphEdge` 代表节点间 Tensor 数据流（原文）。

5. **数据类**：`TensorInfo`（记录 id、varname、dtype、shape）；`OperatorRecord`（记录 op_name、inputs、outputs、traceback）（原文）。

6. **可扩展机制**：新增 Extractor 必须实现 `create`（静态方法）、`target_module`（属性）、`dummy_inputs`（属性），可选重写 `_extract_raw_dag` 与 `_post_process_dag`；新增 Formatter 通过 `@register_formatter("name")` 装饰器注册，函数签名 `def my_formatter(graph: ComputationGraph) -> str:`（原文）。

7. **依赖选型**：直接依赖 `networkx`（PyTorch 已有依赖），无需新增第三方依赖（原文）。

## 【关键机制与数据】

**工作原理与数据流**：

- **提取主流程**：Extractor 通过 `create(...)` 创建实例（传入目标 module、args/kwargs 或 tokenizer、model_path 等）→ 调用 `extract_dag()` → 执行模型时由 `Exec Observer` 捕获算子调用 → 构建以 `GraphNode`（算子）与 `GraphEdge`（Tensor 流）为元素、`ComputationGraph`（继承自 `networkx.DiGraph`）为容器的有向图 → 通过 Formatter 格式化为字符串（默认支持 `dot` 格式）（原文）。

- **图访问接口**：
  - 遍历：`graph.iter_nodes()` / `graph.iter_edges()`（原文）
  - 节点导航：`node.get_successors()` / `node.get_predecessors()`（原文）
  - 边端点：`edge.get_source_node()` / `edge.get_target_node()`（原文）
  - 节点信息：`node.operator.op_name`（原文）
  - 边信息：`edge.tensor.varname`、`edge.tensor.shape`（原文）
  - 格式化导出：`graph.format("dot")`（原文）

- **执行环境要求**：示例代码中均使用 `.npu()` 将模型与输入放到 NPU 设备，依赖 `torch_npu`；TransformerExtractor 示例模型为 `Qwen/Qwen3-0.6B`，TransformerAutoExtractor 示例模型为 `meta-llama/Llama-2-7b-hf`（原文示例代码）。

- **DeepSeek V4 减配策略**（原文示例 4）：
  - `num_hidden_layers=5`（覆盖层内与层间模式）
  - `dim=512`（降低显存占用、加快提取）
  - `moe_inter_dim=256`（降低显存占用、加快提取）
  - 输入：`torch.randint(0, model_args.vocab_size, (1, 1)).npu()`
  - 设备：`torch.set_default_device('npu')`

- **持久化方式**：示例中均将图同时保存为 `.dot` 文件（`graph.format("dot")` 输出）与 `.pkl` 文件（`pickle.dump(graph, f)`）（原文示例）。

**性能数据**：原文未涉及具体性能数据/基准测试结果。

## 【使用方法】

**Extractor API 启用方式**（原文给出三套对应不同模型的工厂方法签名）：

1. **`NativeModuleExtractor`**——任意 PyTorch `nn.Module`：
   ```python
   extractor = NativeModuleExtractor.create(
       module=my_model,
       args=(input_tensor,),
       kwargs={},
   )
   graph = extractor.extract_dag()
   ```

2. **`TransformerExtractor`**——已加载的 Transformers 模型：
   ```python
   extractor = TransformerExtractor.create(
       model=model,
       tokenizer=tokenizer,
   )
   graph = extractor.extract_dag()
   ```

3. **`TransformerAutoExtractor`**——从路径自动加载：
   ```python
   extractor = TransformerAutoExtractor.create(
       model_path="meta-llama/Llama-2-7b-hf",
       trust_remote_code=False,
   )
   graph = extractor.extract_dag()
   ```

**计算图结构 API**（原文）：

- 导入路径：
  ```python
  from msmodelslim.core.graph.fast_ops_grapher import ComputationGraph, TensorInfo, OperatorRecord
  from msmodelslim.core.graph.fast_ops_grapher.exec_observer.exec_dag import GraphNode, GraphEdge
  ```
- 遍历：`for node in graph.iter_nodes(): ...`、`for edge in graph.iter_edges(): ...`
- 节点导航：`node.get_successors()`、`node.get_predecessors()`
- 边端点：`edge.get_source_node()`、`edge.get_target_node()`
- 导出：`dot_str = graph.format("dot")`

**自定义 Formatter 注册**（原文）：
```python
@register_formatter("my_format")
def my_formatter(graph: ComputationGraph) -> str:
    # 实现格式化逻辑
    pass
```
函数签名规范：`def my_formatter(graph: ComputationGraph) -> str:`，通过 `iter_nodes()`、`iter_edges()`、`get_node()` 等接口访问图内容。

**新增 Extractor 必须实现**（原文）：
- `create`（静态方法 + 工厂方法）
- `target_module`（属性，返回目标 PyTorch 模型）
- `dummy_inputs`（属性，返回虚拟输入数据）

可选重写：`_extract_raw_dag`（执行模型并提取原始图）、`_post_process_dag`（对原始图做后处理）。
