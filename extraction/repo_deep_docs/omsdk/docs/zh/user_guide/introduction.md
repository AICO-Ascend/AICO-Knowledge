# 一体化深度解读：OM SDK 产品简介

## 【定位】

本篇文档定位为 **OM SDK（边缘管理系统软件开发套件）的产品入门概览**，解决"开发者/第三方ISV如何基于昇腾算力芯片快速搭建边缘设备硬件管理平台、简化运维部署"的问题，描述的是 OM SDK 作为开发态组件所能提供的端边云框架下的边缘设备管理与对接能力。

---

## 【技术要点】

1. **SDK 定位**：OM SDK 是面向开发态的开发套件，使能第三方 ISV（Independent Software Vendor）或开发者基于昇腾算力芯片快速构建硬件管理平台，简化硬件设备运维部署。
2. **九大类功能能力**（硬件管理、软件管理、时间管理、网络管理、存储管理、用户管理、系统监测、北向接口等）：
   - 硬件层支持查询整机/模组版本型号健康状态、电压温度功耗、硬件故障检测。
   - 软件层支持 OS/驱动固件升级（含升级前检查、升级后回退）、软件版本算力内存查询、一键式开局与免软调上线、OM SDK 自身的安装与升级。
   - 时间层支持时区/系统时间配置与 NTP 从服务器同步。
   - 网络层支持 ETH/WiFi/LTE 多网络设备配置、手动配置 IP/端口/VLAN/网关/DNS、DHCP 自动获取 IP。
   - 存储层支持本地存储分区/容量/健康状态查询，以及 NFS 挂载/容量/连接健康状态。
   - 用户管理层支持密码有效期、登录规则、弱口令与密码修改、可定制化安全策略、可信根导入、Web 证书导入与有效期检查。
   - 系统监测层支持告警上报/屏蔽/历史/当前告警查询、增量设备与关键进程告警集成、安全日志/操作日志/运行日志/黑匣子记录与远程 syslog。
3. **北向对接能力**：支持对接 SmartKit 软件、华为 FusionDirector 管理软件，实现集中式运维管理；提供 RESTful 开放接口并满足服务器北向接口标准。
4. **支持的产品形态**（原文表 2）：仅明示 **Atlas 200I A2 加速模块（RC 模式）** 与 **Atlas 200I DK A2 开发者套件** 两款形态，对应操作系统为 **openEuler 22.03** 与 **Ubuntu 22.04**。
5. **参考设计声明**：边缘管理系统仅作为参考设计提供，不构成对第三方软件产品的功能/性能/安全性/合规性保证；不承诺后续版本升级、功能扩展、漏洞修复等服务支持。

## 【关键机制与数据】

- **原文：** OM SDK 作为"开发态组件"出现，强调"使能第三方ISV或者帮助开发者基于昇腾算力芯片快速搭建硬件管理平台"，定位是边缘端管理能力的 SDK 化封装。
- **原文：** 集中式运维管理通过两条对接链路实现——上层对接 **SmartKit 软件**，上层/北向对接 **华为 FusionDirector 管理软件**。
- **原文：** 数据流方面，OM SDK 在设备端采集「整机/模组硬件信息」「电压/温度/功耗」「软件版本/算力/内存占有率」「系统分区/存储/NFS 状态」「告警与日志」等数据，通过 RESTful（满足服务器北向接口标准）向北开放给 FusionDirector / SmartKit 进行集中纳管。
- **原文：** 性能/容量类具体数值（如支持节点数、并发上限、带宽、延迟等）在本篇概览中**未给出**，仅描述能力项维度。
- **原文：** 时序同步采用 **NTP 从服务器同步** 方式，未涉及 PTP/自建时间源等其他机制。

## 【表格解读】

### 表 1 — 边缘管理系统功能介绍

| 功能类型 | 详细功能介绍 |
| --- | --- |
| 硬件管理 | 硬件信息查询：查询整机硬件版本、型号、健康状态；查询模组软硬件版本、型号、健康状态；查询电压、温度、功耗等信息；硬件故障检测。 |
| 软件管理 | 系统 OS、驱动固件升级：升级前检查；系统固件升级后回退。软件信息查询：查询软件版本、算力、内存占有率。一键式开局和免软调上线。OM SDK 的安装和升级。 |
| 时间管理 | 系统时区、系统时间配置；支持 NTP 从服务器同步时间。 |
| 网络管理 | 支持 ETH、WiFi、LTE 等多种网络设备配置；支持手动配置系统网口的 IP、端口、VLAN、网关、DNS；支持 DHCP 从 Server 端获取系统 IP。 |
| 存储管理 | 支持查询和配置本地存储：查询系统分区、存储容量和分区健康状态。支持配置、查询 NFS 存储系统，如 NFS 挂载，容量显示，连接健康状态。 |
| 用户管理 | 支持密码有效期，登录规则、弱口令设置、查询，支持用户密码修改；支持用户可定制化的安全策略，支持客户可信根导入；支持 Web 证书导入、查询和有效期检查。 |
| 系统监测 | 支持告警上报，告警屏蔽、历史告警查询、支持当前告警显示；支持客户增量设备、关键进程的告警集成显示、管理；系统支持安全日志、操作日志、运行日志、黑匣子记录，支持日志收集、查询、远程 syslog。 |
| 北向接口 | 系统功能支持 FusionDirector 集中纳管协议，支持 RESTful 开放接口，RESTful 满足服务器北向接口标准。 |

**逐行解读：**
- **硬件管理**：覆盖"整机-模组-传感器"三层硬件可观测性（版本/型号/健康状态 + 电压/温度/功耗），并叠加主动故障检测，构成 OM SDK 的设备物联感知底座。
- **软件管理**：以 OS/驱动固件升级为重心，强调"升级前检查 + 升级后回退"的双向保护；"一键式开局、免软调上线"是为 ISV 降低首次部署门槛的关键能力。
- **时间管理**：仅给出最基础的能力——本地时区/时间配置 + NTP 客户端同步，未涉及更高阶的时钟源冗余或时间戳精度指标。
- **网络管理**：明确覆盖有线（ETH）、无线（WiFi）、蜂窝（LTE）三类链路，参数面包含 IP/端口/VLAN/网关/DNS 五项手动配置项，加 DHCP 自动获取，链路与协议面比较完整。
- **存储管理**：本地存储侧聚焦分区/容量/健康度三维；外置存储侧只点明 NFS（未见 iSCSI/CIFS 等其他网络存储协议）。
- **用户管理**：安全策略点涵盖口令生命周期、登录规则、弱口令、可信根、Web 证书，构成端侧准入与可信链的最小集合。
- **系统监测**：告警维度（上报/屏蔽/历史/当前 + 增量设备/关键进程集成）+ 日志维度（安全/操作/运行/黑匣子 四类 + 本地收集 + 远程 syslog），构成"告警-日志"双轨可观测体系。
- **北向接口**：明确将 FusionDirector 集中纳管协议作为一等公民，并以 RESTful + 服务器北向接口标准作为通用开放形态，便于 ISV 接入自有平台。

## 【关联】

- **与 SmartKit 的关系**：OM SDK 在边缘端提供设备/软件/网络/存储等管理能力，**向上对接 SmartKit 软件**，由 SmartKit 承担上层工具链/集成开发侧能力（原文表述为"支持与SmartKit软件对接，实现集中式运维管理"）。
- **与 FusionDirector 的关系**：OM SDK 提供 **FusionDirector 集中纳管协议**支持，并通过满足"服务器北向接口标准"的 RESTful 开放接口对外，可被 FusionDirector 等上层管理平台直接纳管，构成"端—边—云"链路中的"边/端"侧管理平面。
- **与昇腾算力芯片的关系**：OM SDK 本身被定位为**基于昇腾算力芯片**的硬件管理能力封装，能力范围与表 2 中列出的 Atlas 200I A2 加速模块 / Atlas 200I DK A2 开发者套件直接绑定。
- **与免责声明的关系**：文中"参考设计、不做保证、不承诺后续升级"的免责条款，与表 2 较窄的产品/OS 支持面共同构成对外支持的边界声明。
