# omsdk · 产品简介（introduction.md）一体化深度解读

## 【定位】

本篇是 OM SDK 在二次开发（secondary_development）域下的 **产品总览/概览文档**，定位是让第三方 ISV 或基于昇腾算力芯片的开发者快速理解 OM SDK 的产品形态、功能边界、软件架构与开发主流程，是后续 `developer_guide.md` 各实操章节的入口与导读。

---

## 【技术要点】

- **产品角色**：OM SDK 是"开发态组件"（非运行态产品），定位为"边缘管理系统开发包"，提供基础功能供开发者二次开发，目的是"简化硬件设备的运维部署，快速构建自定义的设备运维系统"。
- **三层内部架构**：OM SDK 由三部分组成——`omsdk_interface`（接口层）、`omsdk_core`（实现层）、`DEVM`/`DeviceManager`（适配层，支持开发者自定义模组）。
- **两类对外接口**：
  - **RESTful 接口**：支持 **Web** 与 **SmartKit** 接入。
  - **云边协同接口**：对接 **FusionDirector** 网管。
- **驱动分层**：驱动分两类——OM SDK **自带驱动**（含 `NPU` 即昇腾 AI 处理器、`system` 即系统资源等基础驱动）和 **扩展驱动**（`extern_drv`，用于扩展新增的外部设备、扩展模组）。
- **OS 与定制能力**：OS 支持 **openEuler 22.03** 与 **Ubuntu 22.04** 两个版本；用户可通过**制卡方式替换 OS**；开发态提供**产品配置能力**（产品名称等）。
- **五大功能特性**：① 通过配置文件对设备对象进行抽象管理；② 对昇腾系列产品管理并支持快速开发新硬件；③ 提供本地北向接口访问设备驱动对象；④ 支持独立部署与被第三方集成（管理华为提供的组件）；⑤ 支持告警上报、日志管理等系统维护能力。

## 【关键机制与数据】

> 以下均为原文中显式出现或可直接推导的机制，无外推。

- **开发态/运行态边界**：原文明确"OM SDK 作为开发态组件"，"OM SDK 支持独立部署和被第三方集成的场景，管理华为提供的组件"——即它本身不是面向终端用户的运行态管理平台，而是给上层系统/集成方提供使能能力。
- **配置驱动机制**：原文"支持对设备对象的抽象管理，通过配置文件方式对设备对象进行定义"——OM SDK 不强绑定具体设备清单，新增设备主要靠"配置 + 驱动"扩展而非改代码主干。
- **云边协同路径**：原文"云边协同接口支持对接 FusionDirector 网管"——OM SDK 是昇腾边侧与 FusionDirector 之间的南向代理层（设备↔OM SDK↔FusionDirector）。
- **RESTful 接入面**：原文"RESTful 接口支持 Web 和 SmartKit 接入"——同一种 RESTful 表面向两种前端形态（Web 控制台与 SmartKit 工具）。
- **新硬件使能路径**：原文"对内通过 DEVM 定义支持自带硬件和用户扩展硬件的驱动使能" + "OM SDK 提供更深层次的昇腾模组开发指导，帮助用户快速扩展和使能新硬件外设"——扩展硬件的关键适配点在 **DEVM 适配层**。
- **OS 替换机制**：原文"用户可通过制卡方式替换 OS"——OS 不是运行时可切换，而是通过"制卡"（即制作镜像）阶段完成替换。
- **免责声明边界**（原文保留）：① 仅作参考设计，不构成对功能/性能/安全性/合规性的保证；② 第三方承担全部设计、开发、测试、发布、运营责任及损害赔偿；③ 不承诺提供后续版本升级、功能扩展、漏洞修复服务。

## 【使用方法】

原文在本概览文档中**未涉及**具体命令、配置项或开关；仅给出以下流程性指引：

- **入场流程**：按"获取软件包 → 准备开发环境 → OM SDK 开发 → 构建软件包"四步推进（详见 `developer_guide.md` 四个对应章节）。
- **OS 选型与替换**：仅可使用 `openEuler 22.03` 或 `Ubuntu 22.04`；替换方式为**制卡**（镜像制作阶段），而非运行时切换。
- **新增硬件外设**：通过 `DEVM` 适配层 + `extern_drv` 扩展驱动路径实现（具体步骤在 `developer_guide.md#om-sdk开发`）。
- **面向不同开发者角色**：
  - 华为开发者 → 多产品适配与扩展；
  - 第三方 ISV/开发者 → 私有硬件设备接入扩展开发。

具体配置项、命令行、参数清单均需进入 `developer_guide.md` 对应锚点查阅，本概览不承载。
