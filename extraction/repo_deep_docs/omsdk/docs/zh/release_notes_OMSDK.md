# OM SDK 版本配套说明 深度解读

## 【定位】

本文档是 OM SDK 26.0.0 开源首版本的 Release Notes，描述该版本的产品配套信息、版本兼容性边界（与昇腾社区旧版不兼容）、病毒扫描结果以及新增的边缘设备管理与北向接口能力。

---

## 【技术要点】

1. **产品版本**：OM SDK `26.0.0`，版本类型为 Release 版本。
2. **配套依赖**：与 Ascend HDK `26.0.RC1`、CANN `9.0.0` 配套发布。
3. **兼容性边界**：作为开源**首版本**，不涉及版本升级，且与昇腾社区上既有 OM SDK 版本**不兼容**。
4. **新增能力一**：支持对边缘设备的**硬件管理、软件安装、系统运维、用户管理**四类能力。
5. **新增能力二**：对外提供北向 **RESTful API 接口** 与 **云边协同接口（collaboration API）**。
6. **安全合规**：版本发布前通过病毒扫描。

---

## 【关联】

- **北向 RESTful API（[./secondary_development/api/RESTful_api.md](./secondary_development/api/RESTful_api.md)）**：OM SDK 对外提供的基础北向接口，承载硬件管理、软件安装、系统运维、用户管理能力；上层平台（如云端管理面）通过该接口对边缘节点下发指令。
- **云边协同接口（[./secondary_development/api/collaboration_api.md](./secondary_development/api/collaboration_api.md)）**：用于云与边缘之间的协同控制，是边云协同平台实现边缘 AI 业务编排与状态同步的关键通道，与 RESTful API 形成「通用管理 + 协同控制」的双接口面。
- **上游依赖**：Ascend HDK 26.0.RC1（提供底层硬件驱动与运行时）与 CANN 9.0.0（提供 AI 推理算子与图执行能力）——OM SDK 处于二者之上的边缘编排与运维层。
- **下游能力**：四大管理能力（硬件管理 / 软件安装 / 系统运维 / 用户管理）作为接口背后的实际业务功能，由这两个 API 接口集合对外暴露。
