# MEF 26.0.0 Release Notes 深度解读

## 【定位】
本篇文档是 MEF（边云协同平台）首个开源 Release 版本（26.0.0）的版本配套与变更说明，用于声明版本号、关联依赖（Ascend HDK / CANN）的配套关系、与昇腾社区既有 MEF 版本的兼容性结论，并首次披露云边管理、容器生命周期、告警事件、组件升级与 RESTful API 等核心能力范围。

---

## 【技术要点】

1. **首个开源 Release 版本**：产品名 MEF，版本号 `26.0.0`，版本类型明确为 Release；配套基础软件为 `Ascend HDK 26.0.RC1` 与 `CANN 9.0.0`，三者构成一套发行版本基线。
2. **云-边节点管理能力**：支持云侧对边侧节点的管理，覆盖边侧节点的**接入**与**容器应用生命周期管理**，即上电注册 → 接入控制 → 应用拉起/停止/升级全链路。
3. **云边告警与事件管理**：支持云侧、边侧两侧告警（Alarm）与事件（Event）的统一采集与管理，可在云侧观测边侧异常状态。
4. **组件升级能力**：提供云侧与边侧两侧组件的升级功能，便于在不重装底座的前提下完成组件演进。
5. **云侧 API 接口暴露**：通过 RESTful 接口向外提供能力（指向 `./user_guide/RESTful.md`），便于第三方平台对接。
6. **兼容性结论**：明确声明"开源首版本**不涉及版本升级**，与昇腾社区上的 MEF 软件版本**不兼容**"，意味着不能由社区旧版直接升级上来，且定义"软件版本兼容性"为：关联软件无需联动升级或打补丁即可支持已有功能。

---

## 【关键机制与数据】

- 原文：本版本为"开源首版本"，不涉及版本升级动作；与昇腾社区上的 MEF 软件版本**不兼容**——表明仓库里没有数据迁移/兼容性适配路径，仅提供净安装使用方式。
- 原文：软件版本兼容性定义为"产品软件版本升级时，其他关联软件不需要联动升级或打补丁，仍然可以支持已有功能"——这是后续 MEF 兼容性承诺的官方定义。
- 原文：病毒扫描结果为"通过"——代表发布包已通过安全扫描流程。
- 原文：业务接口变更、关键特性变更、已解决的问题、遗留问题、升级过程对现行系统的影响、升级后对现行系统的影响、漏洞修补列表——以上七项均为"无"，说明这是一个**首次公开发行**而非迭代版本，所有能力均为新增，无既有行为的兼容或回退考量。
